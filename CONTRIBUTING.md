# Contribuir

Ejecuta `npm test` y `./gradlew assembleDebug lintDebug` antes de enviar cambios. Describe firmware, modelo de MG-30, Android y conexión cuando reportes un fallo.

Usa fixtures sintéticos. No adjuntes bancos personales, IR comerciales, NAM ajenos ni capturas con credenciales. Si agregas un control binario o comando MIDI, proporciona evidencia de sus offsets/mensajes y un roundtrip; no adivines el protocolo ni habilites escrituras persistentes sin pruebas.

El proyecto mantiene JS/HTML local y un bridge Java nativo pequeño. No requiere login, analíticas ni servicios en nube.
